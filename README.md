1. Project Analysis
1.1. User Profile: User Persona

The final users of this website will mainly be recruiters, human resources professionals and software development companies looking for students or junior developers.
They expect to find information about my education, technical skills, programming knowledge and personal projects. They also want to understand my interests in computer science and see examples of what I can do.
The website must present this information in a clear and organised way, so users can find what they need quickly. They also expect to find links to my GitHub, as well as my email address, to learn more about my work or contact me.
For this reason, the website needs to have a simple and professional design, with easy navigation and a clear structure.

1.2. Information Architecture

The website is a single-page website divided into five main sections: Introduction, Academic Summary, Projects, Technical Skills, Education and Contact. These sections organise the content and help visitors understand my background and experience.
The first section, Introduction, presents me as a Computer Engineering student at the University of Girona. It includes my name, a short description of my interests in software, algorithms and computer systems, and an image related to programming.
The second section, Academic Summary, provides a quick overview of my main programming languages, problem-solving skills, university studies and academic projects. This allows visitors to identify the most relevant information at a glance.
The third section, Projects, presents two academic programming projects developed using Java and C++. Each project includes a title, a description and a link to its GitHub repository. This section demonstrates how I have applied programming concepts and technical knowledge in practical assignments.
The fourth section, Technical Skills, displays the programming languages, computer science concepts, computer systems knowledge, networking tools and spoken languages I have worked with or studied.
The fifth section, Education, describes my academic background. It includes my Computer Engineering degree at the University of Girona (UdG), my Scientific Baccalaureate and my Secondary Education studies at Institut Ridaura.
Finally, the Contact section provides my email address, GitHub profile and phone number. This makes it easier for recruiters and other professionals to contact me or find more information about my work.

1.3. Visual Design

The visual design is simple and professional. Its aim is to show my education, technical skills and projects clearly, without unnecessary elements.
The website uses dark blue (#111827) as the main background and dark grey (#1F2937) for cards and sections. Blue (#2563EB) and light blue (#60A5FA) highlight important information. Almost white (#F9FAFB) is used for the main text, while grey (#9CA3AF) is used for secondary text.
The typography uses Inter, with Arial as a backup font. Large headings organise the content, while smaller text is used for descriptions.
The website has a single-page layout. It includes an introduction with text and an image, followed by sections for academic information, projects, technical skills, education and contact details. Cards help organise the information and keep the design clear.
